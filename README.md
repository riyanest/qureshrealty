## 🚀 Instant Vercel Deployment

### Method 1: Deploy with GitHub (Recommended)
1. Initialize git and push this folder to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Sunteck Belvedere Park Next.js landing page"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. Log into [Vercel](https://vercel.com).
3. Click **"Add New..."** > **"Project"**.
4. Import your GitHub repository.
5. Vercel automatically detects Next.js. Click **"Deploy"**!

### Method 2: Deploy using Vercel CLI
```bash
npm i -g vercel
vercel
```
